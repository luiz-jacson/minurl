Conheça o MinUrl

Por que o MinUrl?

O MinUrl é um projeto de estudo e portfólio, com o objetivo de aplicar conhecimentos de desenvolvimento backend e frontend em uma aplicação funcional.

Além da interface, o projeto envolve a criação de endpoints, o processamento de formulários, a persistência de dados e a configuração de um ambiente de execução.

A proposta é evoluir a aplicação gradualmente, priorizando código organizado, validações adequadas e uma experiência de uso simples e intuitiva.

Tecnologias utilizadas

Java

Linguagem utilizada na implementação da lógica da aplicação.

Spring Boot

Framework utilizado para estruturar a aplicação web e seus endpoints.

Thymeleaf

Integração entre os templates HTML e os dados disponibilizados pelo servidor.

Bootstrap

Componentes, estilos responsivos e recursos visuais da interface.

PostgreSQL

Banco de dados relacional utilizado para persistência das informações.

Git

Controle de versão para acompanhar a evolução do código-fonte.
